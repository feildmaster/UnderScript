---
title: Import a deck from a link
date: 2023-07-08
version: 0.54.0
---

Opening the Decks page with a deck code in the address loads that deck for you. Both of these work:

* `https://undercards.net/Decks?deckCode=CODE`
* `https://undercards.net/Decks?deck=CODE`

Replace `CODE` with a deck code, so decks can be shared as links.
