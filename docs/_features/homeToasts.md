---
title: Home page announcements as toasts
date: 2021-08-12
version: 0.46.0
---

Announcements on the home page for new bundles, skins, emotes, quest passes, and cards are turned into toasts that you can dismiss, so they stop taking up room. Once dismissed, an announcement stays gone until there is a new one.

Each kind can be turned off in the Home settings, which shows the announcement on the page like normal.
