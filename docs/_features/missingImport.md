The import arrow on each deck in the Deck Hub is colored to show what you would be missing if you imported it.

* Red: you are missing a DT
* Orange: you are missing one or more cards
* Yellow: you are missing one or more artifacts

If more than one applies, the most serious color wins, in the order above. An arrow that stays white means you own everything in the deck.

The first time you visit the Deck Hub a toast explains the colors.
