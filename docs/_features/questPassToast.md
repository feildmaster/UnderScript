---
title: Quest pass toasts
date: 2021-05-30
version: 0.44.0
---

The announcement for a new quest pass on the home page is turned into a toast that you can dismiss, so it stops taking up room. Once dismissed, it stays gone until there is a new quest pass.

Turn it off in the Home settings to show the announcement on the page like normal.

See also: [Skin Toasts]({% link _features/skinToasts.md %}), [Bundle and emote toasts]({% link _features/toastContent.md %}), [New card toasts]({% link _features/cardToast.md %}).
