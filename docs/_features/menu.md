UnderScript has its own menu, which you open from the Undercards menu. It has:

* Settings
* The change log
* Community Plugins
* Check for updates
* Reload Cards, which refreshes the card data when something looks out of date

The Undercards menu also gets an UnderScript section with links to the Card Editor and Leaderboard+.
