UnderScript has its own menu, which you open from the Undercards menu, or by pressing Escape. It has:

* Check for updates
* Show Pending Updates, which lists everything that is waiting to be installed
* The change log
* Community Plugins
* Game Patch Notes, which opens the game's own patch notes
* Reload Cards, which refreshes the card data when something looks out of date
* Settings

The Undercards menu also gets an UnderScript section with links to the Card Editor and Leaderboard+.
