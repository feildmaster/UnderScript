Suggestions pop up above the chat box as you type.

* Names of recent users in the room are suggested after `@`, along with your friends. You can limit the friends to the ones that are online
* `/` suggests [chat commands]({% link _features/chatCommands.md %}), with a short description and how to use them
* `:` suggests emotes

`@` suggestions came first, with commands and emotes added in 0.64.0. Each one can be turned off in the Chat settings.
