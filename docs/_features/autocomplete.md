title: Chat autocomplete
date: 2026-08-28
version: 0.64.0
---

Suggestions pop up above the chat box as you type.

* `/` suggests chat commands, with a short description and how to use them
* `:` suggests emotes
* Names of friends are suggested after `@`, and you can limit that to friends that are online

Each one can be turned off in the Chat settings.
