Install it

  1. Install Tampermonkey and UnderScript. In Chrome, Edge and Opera, also allow Tampermonkey to run userscripts.
  2. Open the Tampermonkey dashboard and add a new script with the + tab.
  3. Replace everything in it with your plugin and save.
  4. Reload undercards. You should see a "Hello from my plugin!" message, and your plugin's settings under Plugins in the UnderScript settings.

What next

The comments in the file explain each part. When you want to do more, the Plugin API lists everything a plugin can do. The plugin template explains how to share your plugin and get it into the Community Plugins menu.
